# 레조넌스 개인 실행기

포켓몬 레조넌스(팬게임) iOS 비공식 포팅의 게임 데이터(`packs.zip`)를 아이폰 홈 화면 앱에서 실행하는 **개인용** 실행기입니다.
원래 사이트 실행기와 달리, 다이나믹 아일랜드·둥근 모서리를 피하도록 게임 화면 가장자리에 여백을 둘 수 있습니다.

- 서버에는 실행기 코드와 위치표(파일 위치 목록 JSON)만 올라갑니다. **게임 데이터는 서버에 올리지 않습니다.** 각자 기기에서 고른 `packs.zip`만 씁니다.
- 외부 서버로 보내는 통계·추적이 없습니다.
- 개인용입니다. 주소를 공유하지 마세요. 검색엔진 색인은 막아 두었습니다(`robots.txt`, `noindex`).

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html`, `launcher.css`, `launcher.js`, `icon-*.png` | 실행기 화면, 설치, 세이브 백업, 화면 여백 설정 |
| `zip.js` | `packs.zip`을 통째로 메모리에 올리지 않고 팩을 하나씩 꺼내는 ZIP 리더 |
| `sw.js` | 서비스 워커. `game/` 아래 요청을 기기에 저장된 팩에서 잘라서 응답 (Range 지원) |
| `release.json`, `manifest-<buildId>.json` | 지금 게임 버전과 위치표 (처음엔 없고, 워크플로나 스크립트가 만듦) |
| `update_manifest.py` | 원래 사이트에서 최신 위치표를 받아 위 두 파일을 갱신 |
| `.github/workflows/deploy.yml` | GitHub Pages 배포 + 매일 위치표 확인·커밋 (GitHub에 올렸을 때) |

## 1. 올리기

### GitHub Pages (권장)
업무용 계정과 분리된 **별도 계정**을 권장합니다. 자세한 순서는 따로 드린 가이드 문서를 보세요.

1. 새 저장소를 만듭니다. 무료 플랜은 **공개 저장소**여야 Pages가 됩니다.
2. **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
3. 폴더 안의 **파일**을 전부 끌어다 올립니다. 폴더는 `.github` 하나뿐이고, 웹 업로드로는 폴더가 안 올라가니 따로 만듭니다.
4. **Add file → Create new file**에서 이름 칸에 `.github/workflows/deploy.yml`을 입력하고(`/`를 치면 폴더가 생김), 같은 파일의 내용을 붙여 넣어 커밋합니다.
5. **Actions** 탭에서 `deploy`가 초록 체크로 끝나면 `https://<계정>.github.io/<저장소>/` 주소가 생깁니다.
6. 같은 실행에서 원래 사이트의 위치표를 받아 `release.json`과 `manifest-<buildId>.json`을 커밋합니다. 이후로는 매일 03:23(한국 시간)에 확인해서, 바뀐 날만 커밋하고 다시 배포합니다.

브랜치 배포(`Deploy from a branch`)를 쓰지 않는 이유가 있습니다. 워크플로가 `GITHUB_TOKEN`으로 푸시한 커밋은 Pages 빌드를 일으키지 않습니다. 그래서 위치표 커밋과 배포를 `deploy.yml` 한 곳에서 처리합니다.

### Cloudflare Pages
1. Workers & Pages → Create → Pages → **Upload assets**를 고릅니다.
2. 이 폴더를 통째로 끌어다 놓습니다.
3. `https://<프로젝트>.pages.dev/` 주소가 생깁니다.
4. 이 방식에서는 자동 갱신이 되지 않습니다. 게임 업데이트 때 아래 2번의 수동 갱신을 하고 다시 올리세요.

## 2. 위치표 갱신 (게임 업데이트 때)

```bash
python3 update_manifest.py              # 원래 사이트에서 직접 받기
python3 update_manifest.py --from-file game-manifest-xxxx.json   # 받아 둔 파일로
```

`release.json`과 `manifest-<buildId>.json`이 바뀌면 그 두 파일을 다시 올립니다. GitHub Pages라면 하루 한 번 자동으로 처리됩니다. 기다리기 싫으면 **Actions → deploy → Run workflow**를 누르세요.

공개 저장소의 예약 실행은 60일 동안 저장소 활동이 없으면 꺼집니다. 꺼졌다면 **Actions → deploy**에서 다시 켜세요.

git으로 작업한다면 푸시 전에 `git pull`부터 하세요. 봇이 위치표 커밋을 넣기 때문입니다.

## 3. 아이폰에 설치

1. **원래 레조넌스 앱에서 세이브 백업을 먼저 내보내 파일 앱에 저장합니다.**
2. Safari에서 위 주소를 엽니다.
3. 공유 → **홈 화면에 추가**를 누릅니다.
4. 홈 화면의 새 **레조넌스** 아이콘으로 실행합니다. Safari 탭과 홈 화면 앱은 저장소가 따로라서, 반드시 앱에서 진행해야 합니다.
5. **packs.zip 선택**을 눌러 원래 사이트에서 받은 `packs.zip`을 고릅니다. 약 1GB를 저장하는 동안 화면을 켜 두세요. 중간에 끊기면 다시 고르면 이어서 설치됩니다.
6. **백업 가져오기**로 1번에서 저장한 파일을 고릅니다.
7. **게임 시작**을 누릅니다.

설치가 끝나면 원래 앱은 지워도 됩니다. 원래 앱을 지우면 그 앱의 세이브도 함께 사라지니, 새 앱에서 세이브가 잘 보이는지 먼저 확인하세요.

## 화면 여백

게임 중 왼쪽의 반투명 **⋯** 버튼(또는 실행기 화면)에서 바꿉니다.

- **좌우만** (기본): 가로 화면에서 다이나믹 아일랜드와 둥근 모서리를 피합니다. 게임 화면이 가장 큽니다.
- **상하좌우**: 아래쪽 홈 인디케이터 영역까지 비웁니다.
- **끄기**: 원래 사이트처럼 꽉 채웁니다.
- **추가 여백**: 모든 방향에 0~40px을 더 비웁니다.

⋯ 버튼이 거슬리면 메뉴에서 **⋯ 버튼 반대쪽으로**를 누르세요.

## 아이폰 조작 보정

- **터치 탭**: iOS 18.2부터 손가락 탭이 게임에 마우스 클릭으로 전달되는 문제(WebKit 버그) 때문에, 미니게임의 B 버튼이나 "화면 탭 = A"가 먹지 않았습니다. 실행기가 이런 탭을 터치로 고쳐서 게임에 넘깁니다. (v1.0.4)
- **메뉴·미니게임 스와이프 방향**: 게임은 메뉴 화면의 스와이프를 목록 스크롤처럼 처리해서, 커서가 손가락과 반대로 움직입니다. 실행기 설정의 **손가락 방향**(기본)을 고르면 필드 이동처럼 손가락 방향대로 움직입니다. **게임 원래대로**를 고르면 원래 동작입니다. 바꾸면 다음에 게임을 시작할 때부터 적용됩니다. (v1.0.5)
  - 서비스 워커가 `app/storyUi-*.js`를 내줄 때 스와이프 부호 두 곳만 바꿉니다. 게임 업데이트로 그 부분이 달라져 찾지 못하면 원본을 그대로 내주므로, 게임이 깨지지는 않고 방향만 원래대로 돌아갑니다.

## 세이브

- 게임 세이브는 이 앱의 localStorage에 있는 `rcb.*` 값들입니다.
- 백업 파일은 게임과 원래 실행기가 쓰는 형식(`pokemon-resonance-backup` v1)과 같습니다. 원래 앱과 이 앱 사이에 서로 옮길 수 있습니다.
- 가져오기 전 세이브는 기기에 따로 보관됩니다. 실행기의 **가져오기 전 세이브로 되돌리기**로 복구할 수 있습니다.
- 앱을 지우거나 iOS가 사이트 데이터를 정리하면 세이브가 사라집니다. 가끔 **백업 내보내기**를 해 두세요.

## 고칠 때 주의

실행기 화면 파일은 서비스 워커가 캐시해서 씁니다. `index.html`·`launcher.*`·`zip.js`를 고쳤다면 `sw.js` 맨 위의 `VERSION`도 올려야 아이폰에 반영됩니다.

## 문제 해결

| 메시지 | 원인과 조치 |
|---|---|
| 버전 정보를 읽지 못했습니다 | `release.json`이 없거나 오프라인입니다. 2번의 위치표 갱신을 하세요. 급하면 고급 메뉴 → 위치표 파일 직접 선택을 쓰세요. |
| 필요한 팩 N개가 고른 파일에 없습니다 | ZIP과 위치표의 버전이 다릅니다. 원래 사이트의 최신 `packs.zip`을 받고, 위치표도 갱신하세요. |
| 팩 내용이 위치표와 다릅니다 | ZIP이 덜 받아졌거나 손상됐습니다. 다시 받으세요. |
| 게임 데이터 일부가 없습니다 (게임 중 503) | 설치가 덜 끝났습니다. 실행기에서 `packs.zip`을 다시 고르세요. |
